# Fort Chip Demon List v2

This version is designed around actual Geometry Dash records.

Features:
- Level database
- Player profiles
- Separate completions and partial runs
- Run ranges such as 30-67%, 32-57%, and 40-100%
- Attempts
- Clickable level pages
- Clickable player profiles
- Search and record filtering
- Mobile-friendly layout

Edit the arrays at the top of `script.js` to add your own levels, players, completions and runs.

Open `index.html` in a browser to test it. For a public site, upload the three files to a GitHub repository and enable GitHub Pages.
